Reason Through the Latent! Making Latent Visual Reasoning Necessary, by Suhyeong Park, Junha Jung, and Jaewoo Kang of Korea University and AIGEN Sciences. On the topology standing rule, this one is squarely a recurrent-depth latent chain-of-thought paper for multimodal models. The premise: latent visual reasoning does computation in hidden states instead of explicit textual chains of thought. Nobody usually checks whether the model actually depends on those hidden states. The authors point out the confound bluntly: if the original multimodal context remains anywhere in the network, whatever latent path you added is decorative and can be bypassed.

Two diagnostic experiments start it. First, weak behavioral reliance: on existing latent visual reasoners, replacing the latent content with a blank-image latent, a matched latent from a different-answer example, or norm-matched noise changes accuracy by almost nothing - one cited method shifts at most half a percentage point across all three replacements - because the normal multimodal answer context is still available. Second, where does pretrained visual competence live? Passing intermediate-layer states of the frozen vision-language model alone into the same frozen upper decoder, the full multimodal question state reaches 75.9 percent on V-star, the multimodal question rows alone reach 75.4, while a text-only question state bottoms out at 35.6 and adding raw visual features to the text-only state recovers nothing. So the competence is already integrated into the question representation, and it isn't reconstructable from raw visual features.

CVRR - Causal Visual Recurrent Reasoning - is built on those two findings and works like this. Using layer-wise activation patching on Qwen2.5-VL-7B to find where visual tokens stop exerting downstream influence, the recurrent boundary lands at layer 20, recurrence starting at layer 21. The frozen lower backbone produces the multimodal question state; the first pretrained decoder layer runs once on it, and the question rows become the initial recurrent state h1 while the visual rows are stored as persistent evidence.
Each recurrent step rebuilds the native multimodal scaffold with the question rows replaced by the current recurrent state, runs the shared pretrained decoder layer with a low-rank adapter, and blends: new state equals the old state plus beta times the layer output. Beta is 0.5. Default recurrent depth is 4. No cross-attention module is added - re-reading happens through the layer's own causal self-attention over the fixed visual rows. The backbone and upper decoder stay frozen; only a rank-32 adapter shares parameters across all recurrent steps, 2.9 million trainable parameters in total. Training is plain answer-token cross-entropy on the Visual CoT dataset, 438 thousand question-answer pairs with bounding boxes. No latent targets, no teacher trajectories.

The decoder interface is what makes the necessity claim causal. Before answer decoding, every visual row and the entire original multimodal KV cache are deleted; the autoregressive answer path uses only text-only question prefix caches, which contain no image-conditioned information. The final recurrent state is therefore the sole image-conditioned input to the answer. Recurrence depth is four, and the same trajectory is used at inference.

Results. On V-star, CVRR reaches 81.2 percent - up 1.6 over the Qwen2.5-VL-7-Instruct backbone, and above GPT-5 at 73.3. MMVP pair accuracy is 52.7 percent, up 5.4; BLINK overall 55.2. Those numbers sit alongside the full multimodal SFT control at 80.6, so CVRR roughly matches ordinary full-context fine-tuning while using the strict bottleneck. The decisive comparison: all latent-reasoning baselines retrained under the same no-bypass interface collapse - the best reaches 39.8 percent on V-star, and MMVP pair accuracy falls to as low as 2.7 percent. The bottleneck alone wipes them out; the path must begin from the native multimodal state.
Ablations cleanly separate the two roles. Swapping the initial state for a text-only equivalent - visual evidence still present, adapter retrained - drops V-star from 81.2 to 37.2 and MMVP pair accuracy to 2 percent, matching removal of the entire visual path: persistent visual access cannot reconstruct native competence. Decoding after a single layer gets 75.4 on V-star but only 22.7 MMVP pair accuracy. Removing visual re-reading costs 12 points on V-star and 34.7 on MMVP pair; removing the learned transition costs 4.7 and 20. Causal interventions confirm dependence: corrupting the recurrent state under the strict interface takes accuracy down to 14 percent, while restoring the multimodal prefix partially rescues corrupted states - which is, the authors note, precisely why latent paths look influential in ordinary deployments but aren't. A cross-state test shows clean visual evidence corrects a wrong recurrent start by about 15 points when question-to-visual connections are enabled and barely moves anything when they're blocked. Depth is examined from 2 to 8; depth 4 is best, 6 slightly worse, 8 recovers.

Engineering takeaways for anyone building latent reasoning: necessity is an interface property, not a training-dynamics property; the alternative answer paths must be structurally removed, and the recurrent path should inherit the pretrained model's integrated visual representation rather than raw features.

Where do I stay skeptical? The benchmarks are small - V-star has 191 examples, MMVP 300 questions over 150 image pairs - so single-digit movements are within noise territory, and CVRR's gains over the SFT control are modest: on it, BLINK overall actually drops slightly versus the control. The gains over prior latent methods are real but concentrated, and the burden of a 4-step-deep recurrence on a frozen backbone is latency that isn't reported. Bottom line: the paper's lasting contribution is methodological - a causal test that separates genuinely necessary latent computation from decorative latent content - and CVRR is a sound template for recurrent multimodal depth, pending replication at larger scale.
The boundary-finding procedure is an underappreciated contribution because it's reusable on any frozen model. Layer-wise activation patching on contrastive pairs - same question, different images yielding different answers - measures at each candidate layer how much swapping visual activations flips the answer preference, normalized by the full-logit margin at layer zero. The boundary is the layer before the first sustained decline in downstream visual influence. For Qwen2.5-VL-7B that's layer 20, and appendix checks show nearby boundaries work nearly as well - so the method is not hypersensitive to the exact layer, which matters for porting. The same patching machinery doubles as the causal intervention tool later, applying the same intervention to Corrupted states to show that persistent visual evidence reshapes the recurrent trajectory rather than merely sitting in it.
Method-lineage context: reusing shared transformer parameters across depth follows the universal-transformer line and the recent recurrent-depth work on looped language models, where weight-tied iteration is the standard trick for adaptive computation at fixed parameter count. What distinguishes CVRR from those models is that recurrence exists to re-read persistent visual evidence within one forward computation, not to deepen abstract reasoning over tokens. The comparison class in the tables makes this concrete: seven prior latent visual reasoners, trained full-time on tasks like MMVP, all trade a few performance points for their latent machinery and lose badly when the bypass is closed - because stock latent reasoners rely on decoding against a full multimodal answer path that CVRR deliberately removes.
The KV-cache discipline is worth spelling out because it's where an implementation would silently leak. Below the recurrent boundary, autoregressive answer tokens use image-free prefix caches built from a text-only question pass; above the boundary, the final recurrent state serves as the question-prefix representation for the frozen upper decoder. All visual rows and the original multimodal prefix caches are discarded before decoding. So the answer decoder holds a trajectory of text-only caches below the boundary, plus the recurrent state as its one image-conditioned view, and nothing else - a compact arrangement that also happens to preserve the model's language competence from the original instructions. Any production implementation needs the same invariant enforced in code, not just in the description.
